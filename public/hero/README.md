# Hero Assets

Este directorio contiene los assets para la ilustración hero compuesta.

## Archivos SVG (requeridos)

- `hero-backplate.svg` - Fondo/base de la ilustración (página blanca)
- `hero-pixels.svg` - Bloques de píxeles decorativos (ya guardados)

## Archivos de imagen (requeridos cuando usePlaceholders=false)

- `hero-person.webp` - Imagen de la persona (señor, transparente) a la derecha
- `hero-laptop.webp` - Imagen de la laptop (transparente) a la izquierda

## Notas

- Los SVG deben ser optimizados para web
- Las imágenes .webp deben tener fondo transparente
- Todos los assets son decorativos y no requieren alt text descriptivo
- Los círculos decorativos se manejan directamente en el componente
